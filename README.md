# oGames - Digital Game Storefront 🎮

A comprehensive, web-based digital game store inspired by platforms like Steam. This ASP.NET Core MVC application provides a fully functional storefront where users can browse, purchase, and review games, alongside a dedicated admin panel for store management.

## ✨ Key Features

* **User Authentication & Roles:** Secure registration and login system with distinct `User` and `Admin` access levels.
* **Storefront & Catalog:** Browse games with sorting and searching capabilities. Each game has a dedicated page with a gallery, price, description, and user ratings.
* **Shopping Cart & Checkout:** Seamlessly add games to the cart and process purchases to add them to your account.
* **User Library:** A personal profile area where users can access their purchased games and leave text reviews with star ratings.
* **Admin Dashboard:** 
  * **Game Management:** Full CRUD (Create, Read, Update, Delete) operations to add new titles, adjust pricing, and edit descriptions.
  * **User Management:** Monitor registered accounts, manage roles, and remove users if necessary.

## 💻 Tech Stack

* **Backend:** C# / ASP.NET Core (MVC Architecture)
* **Database:** SQLite (Entity Framework Core)
* **Frontend:** HTML, CSS, JavaScript (Razor Views)

## 🚀 Getting Started

The project is configured to be easily runnable locally. 

### Prerequisites
* [.NET 9.0 SDK](https://dotnet.microsoft.com/download) (or compatible version) installed.
